# Login logo

`nixos-logo.txt` is Fastfetch's `nixos2` ASCII artwork, vendored from revision `6a82126aa99a81bd4c083f37ef52c140c1438c40`.

Source: https://github.com/fastfetch-cli/fastfetch/blob/6a82126aa99a81bd4c083f37ef52c140c1438c40/src/logo/ascii/n/nixos2.txt

MIT license: see FASTFETCH-LICENSE. `$1`/`$2` are upstream colour placeholders; Hearth maps them to its console coral/gold ANSI slots. Rows are padded to equal visible width before centering. No runtime download or Fastfetch executable is needed. Pure ASCII avoids missing Unicode sextant/Nerd Font glyphs in the Linux console.
